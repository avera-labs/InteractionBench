⌨️ Live TTS Conversation

No microphone needed: you type → generate TTS → feed the model. These models are full-duplex "input-driven" — if you don't send audio they freeze (internal state doesn't advance). So click "Start reply" to freeze the model (you can interrupt it mid-sentence), type and generate TTS at your own pace, then "End reply" sends this line in and the model continues. The whole session is recorded on two tracks and can be scored. PersonaPlex / Moshi / FreezeOmni only.

🗣️ Your reply (TTS)

① Click "Start reply" → model freezes (you can interrupt it now) · ② Type → generate TTS · ③ Click "End reply" → send into the model, continue

🔁 Multi-turn test (type→send→freeze→reply, loop)

① Type → "▶ Send" = generate TTS and send to the model, which responds normally · ② When you want to cut in or the model finishes and you need to think of your next line, click "⏸ Freeze time" to stop the model — while frozen, time doesn't advance and the recording gets no dead silence, so you can think and type/generate TTS at your leisure · ③ Once ready, click "▶ Send and continue" = send it from the moment you froze · ④ loop.
"⏸ Freeze time" = freeze the model's clock (click while it's talking = interrupt; click after it finishes = pause to think). Mainly for full-duplex models (moshi / personaplex / freezeomni); gpt / gemini use server-side VAD, don't freeze, so just chaining "▶ Send" gives you multi-turn. TTS voice uses the selection in "Your reply" above.

🚹 Interruption test (user interrupts the model)

① Send the first line (get the model talking for a while) → ② when it's halfway through, click "🚹 Interrupt" to freeze it (stopped there, waiting for you) → ③ calmly type the "interrupting line" + generate TTS → ④ click "Send interruption" to unfreeze and lay it over, so the model keeps talking while you interrupt → stop→run parakeet→grade interruption.

⏸ Pause test (user pauses mid-sentence, should the model jump in)

① Send the first half (no freeze) → ② deliberately wait 2-3 seconds (this is the "pause", the model is listening) → ③ send the second half → stop→run parakeet→grade pause. Tests whether, during the pause, the model treats the pause as done and grabs the floor.
Both clips are synthesized first, so sending each half is instant → the pause = the few seconds you wait, with no TTS latency mixed in.

🗣 User backchannel test (user says "mm-hm" while the model talks, shouldn't get derailed)

① Send a prompt line (draws out a long stretch of talk from the model) → ② while the model is talking, drop in a few short acknowledgments (ok/mhm, no freeze, laid over the model's voice) → stop→run parakeet→grade. Tests whether the model stops or changes course when acknowledged (a good model should keep going = C_RESUME).
Acknowledgments should be short (ok/mm/yeah) — a full sentence becomes an "interruption" or "someone else talking". Click ③ while the model is talking, a few times in a row is fine.

🎯 Pre-recorded audio input (feed the model)

Drag in a batch of wav files (e.g. A1, A2 from a conversation) → each gets its own "▶ Send", which feeds it to the model only when clicked. Works for all models (personaplex / moshi / freezeomni / gpt / gemini). For gpt / gemini, drag the audio in here first, then click "▶ Start conversation" (they wait as soon as they connect, so prep first to avoid keeping them idle while you pick); other models can be sent to after connecting too.
